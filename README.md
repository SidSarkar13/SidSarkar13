## 👨‍💻 About Me

I design and manage cloud infrastructure on Azure — VNet architecture, NSG, NAT Gateway, Private Endpoints, and Databricks platform administration, all delivered through **Bicep-based IaC** across dev, QA, and prod environments.

Outside of work I'm building **Tactix** — a football AI video analysis tool that does player detection, tracking, expected threat (xT) modeling, and pass network visualization using React + FastAPI + Claude API.
